CLAI is an MCP server that bridges your documentation and the AI assistants your team already uses. Instead of relying on outdated training data, tools like Claude Desktop, Cursor, and VS Code Copilot can query your actual docs in real time — giving users accurate, grounded answers drawn directly from the content you maintain.

## What is CLAI?

AI assistants are powerful, but they hallucinate when asked about your product. They were trained on a snapshot of the internet, not your latest API reference or your most recent release notes. CLAI solves this by exposing your documentation as a set of tools over the **Model Context Protocol (MCP)** — an open standard by Anthropic for connecting AI applications to live, external data.

When a user asks an AI assistant a question about your product, CLAI intercepts that query, searches your docs, and returns the most relevant content. The AI then uses that content to craft a precise, up-to-date answer. No fine-tuning. No stale responses.

## Prerequisites

Before you get started, make sure you have the following:

- **Node.js 18 or later** installed on your machine
- **An existing docs site or a directory of Markdown files** — CLAI needs something to read
- **An MCP-compatible AI client** such as Claude Desktop, Cursor, or VS Code with the Copilot extension

<Tip>
  If your docs are built with **Fumadocs**, you're already set up for the fastest possible integration. Fumadocs sites expose an `llms.txt` route by default, which CLAI can read directly — no extra configuration needed.
</Tip>
