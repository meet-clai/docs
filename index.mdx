Welcome to the Clai documentation. Clai is available at [app.goclai.com](https://app.goclai.com), where you manage your account, configure your workspace, and issue credentials for API access.

## API keys

All API keys for the Clai platform are issued from the Clai app. Sign in at [app.goclai.com](https://app.goclai.com) to manage them.

<Card title="Create an API key" icon="key" href="https://app.goclai.com/settings/api-keys">
  Go to **Settings → API keys** in the Clai app to create, view, and revoke keys.
</Card>

<Note>
  Treat API keys like passwords. Store them in a secret manager and never commit them to source control. If a key is exposed, revoke it immediately from [Settings → API keys](https://app.goclai.com/settings/api-keys).
</Note>
