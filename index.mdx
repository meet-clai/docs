CLAI exposes your documentation to AI assistants through the [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — an open standard that lets tools like Claude, Cursor, and VS Code Copilot search, retrieve, and reason over your docs in real time. Whether you're using Fumadocs, Mintlify, or any Markdown-based docs site, CLAI makes your documentation a first-class data source for AI.

## Get Up and Running

<Steps>
  <Step title="Install CLAI">
    Add the CLAI MCP server to your project using your preferred package manager.

    ```bash
    npm install -g clai
    ```
  </Step>
  <Step title="Point it at your docs">
    Create a `clai.config.json` file and add your documentation source — a URL, a local path, or an `llms.txt` endpoint.

    ```json clai.config.json
    {
      "sources": [
        { "type": "url", "url": "https://your-docs-site.com/llms.txt" }
      ]
    }
    ```
  </Step>
  <Step title="Connect your AI client">
    Register CLAI as an MCP server in Claude Desktop, Cursor, or VS Code. Your AI assistant can now search and retrieve your docs automatically.
  </Step>
  <Step title="Ask questions">
    Open your AI assistant and ask questions about your docs. CLAI's `search`, `list_pages`, and `get_page` tools will fetch the right content automatically.
  </Step>
</Steps>
