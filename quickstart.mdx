---
title: "Quickstart: Run CLAI and Connect Your AI Assistant"
sidebarTitle: "Quickstart"
description: "Install CLAI, configure a Fumadocs or Markdown documentation source, and have your AI assistant querying live docs in under five minutes."
---

By the end of this guide, you'll have CLAI running as an MCP server connected to your documentation, with your AI assistant able to search and retrieve your docs automatically. All you need is Node.js 18+ and an existing docs site or folder of Markdown files.

<Steps>
  <Step title="Install CLAI">
    Install the CLAI CLI globally using your preferred package manager.

    <CodeGroup>
      ```bash npm
      npm install -g clai
      ```
      ```bash yarn
      yarn global add clai
      ```
      ```bash pnpm
      pnpm add -g clai
      ```
    </CodeGroup>

    Verify the installation:

    ```bash
    clai --version
    ```
  </Step>

  <Step title="Create your config file">
    Create a `clai.config.json` file in your project root. Add at least one documentation source — a URL pointing to your `llms.txt` file is the fastest way to get started.

    ```json clai.config.json
    {
      "sources": [
        { "type": "url", "url": "https://your-docs-site.com/llms.txt" }
      ]
    }
    ```

    If you have local Markdown files, use a `local` source instead:

    ```json clai.config.json
    {
      "sources": [
        { "type": "local", "path": "./docs" }
      ]
    }
    ```

    <Note>
      **Using Fumadocs?** Fumadocs sites expose an `llms.txt` route automatically. Point CLAI at `https://your-docs-site.com/llms.txt` and CLAI will discover and index all your pages without any extra setup. See the [llms.txt guide](/guides/llms-txt) for details.
    </Note>
  </Step>

  <Step title="Start the CLAI server">
    Run CLAI in STDIO mode (recommended for local AI clients like Claude Desktop and Cursor):

    ```bash
    clai start --stdio
    ```

    Or in HTTP mode for remote or team access:

    ```bash
    clai start --http --port 3000
    ```

    CLAI will index your sources on startup and confirm how many pages were found.
  </Step>

  <Step title="Connect to your AI client">
    Register CLAI as an MCP server in your AI client. For Claude Desktop, open the config file for your platform:

    - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
    - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

    Add the following entry:

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "clai": {
          "command": "clai",
          "args": ["start", "--stdio"],
          "cwd": "/path/to/your/project"
        }
      }
    }
    ```

    Replace `/path/to/your/project` with the directory containing your `clai.config.json`. Then restart Claude Desktop.
  </Step>

  <Step title="Test the integration">
    Open your AI assistant and ask a question about your documentation:

    > "What does the authentication guide say about API keys?"

    Your AI client will automatically call CLAI's `search` tool, retrieve relevant excerpts from your docs, and use them to answer with grounded, accurate information.
  </Step>
</Steps>
