title: "Integrate CLAI with Cursor IDE as a Local MCP Server"
sidebarTitle: "Cursor"
description: "Add CLAI as an MCP server in Cursor so your AI coding assistant can reference your documentation while writing and reviewing code."
---

Cursor supports MCP servers through its built-in settings panel — connect CLAI to give Cursor's AI access to your documentation while you code. Once connected, Cursor's chat agent will automatically search and retrieve pages from your docs whenever they're relevant to what you're building.

## Prerequisites

- CLAI installed and a `clai.config.json` present in your project directory
- Cursor version with MCP support (Settings > Features > MCP must be visible)

## Setup

<Steps>
  <Step title="Open Cursor settings">
    Open the Cursor settings panel with **Cmd+Shift+J** on macOS or **Ctrl+Shift+J** on Windows and Linux. Navigate to **Features > MCP** in the left sidebar. You'll see a list of any already-configured MCP servers and a button to add new ones.
  </Step>

  <Step title="Add a new MCP server">
    Click **Add MCP Server**. Cursor will prompt you to choose a transport type — select **stdio**. This mode runs CLAI as a local subprocess that Cursor communicates with over standard input and output.
  </Step>

  <Step title="Enter the CLAI command">
    Fill in the server details:

    | Field | Value |
    |---|---|
    | **Name** | `clai` |
    | **Command** | `clai` |
    | **Arguments** | `start --stdio` |
    | **Working directory** | Path to your project root (where `clai.config.json` lives) |

    If `clai` isn't in your shell's PATH, use the absolute path to the binary instead (e.g., `/usr/local/bin/clai`).
  </Step>

  <Step title="Save and reload">
    Click **Save**. Cursor will immediately attempt to connect to CLAI. Return to the **Features > MCP** panel — the server entry should show a green **active** status within a few seconds, confirming the connection succeeded.
  </Step>

  <Step title="Use CLAI in Cursor Chat">
    Open Cursor Chat with **Cmd+L** (macOS) or **Ctrl+L** (Windows/Linux). Make sure the chat is in **Agent** mode — look for the mode selector at the top of the chat panel and switch to Agent if needed. Now ask about your documentation:

    > "What parameters does the `createUser` API endpoint accept according to our docs?"

    Cursor will call CLAI's `search` or `get_page` tool and ground its answer in your actual documentation.
  </Step>
</Steps>

## Alternative: JSON config for teams

If you want to share the CLAI setup with your whole team through version control, create a `.cursor/mcp.json` file in your project root instead of — or in addition to — the GUI settings:

```json
{
  "mcpServers": {
    "clai": {
      "command": "clai",
      "args": ["start", "--stdio"]
    }
  }
}
```

<Tip>
  Commit `.cursor/mcp.json` to your repository. Any teammate who opens the project in Cursor will automatically get CLAI wired up without touching their own settings. Pair this with a shared `clai.config.json` and your entire team's AI assistant will reference the same documentation sources.
</Tip>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server shows as disconnected">
    If the MCP panel shows CLAI as disconnected or errored, try these steps:

    1. **Check PATH** — open a terminal inside Cursor (**Terminal > New Terminal**) and run `which clai`. If the binary isn't found, update the command field in your MCP config to use the full absolute path.
    2. **Verify the working directory** — the directory must contain `clai.config.json`. Cursor uses that path as the process working directory; a wrong value means CLAI can't find its config and exits immediately.
    3. **Look at the error details** — hover over the red status indicator in the MCP panel for a short error message. The full stderr output from CLAI appears in Cursor's output panel under **View > Output > MCP**.
  </Accordion>

  <Accordion title="Cursor doesn't call CLAI tools">
    Cursor's AI only invokes MCP tools when the chat is running in **Agent** mode. In regular Chat or Edit mode, tools are not available.

    Switch to Agent mode using the mode selector at the top of the Cursor Chat panel. Once you're in Agent mode, the connected MCP servers — including CLAI — become part of the agent's tool set. You can verify this by clicking the tools icon in the chat panel, which lists every available tool by server.

    If tools are still not called, try prompting more explicitly: *"Search my documentation for…"* or *"Use CLAI to look up…"*
  </Accordion>
</AccordionGroup>
